# مِسار — نظام إدارة مدرسة

## التشغيل
1. ثبّت Python 3.9+ (لا مكتبات إضافية). 2. انسخ `.env.example` إلى `.env`. 3. شغّل `run_masar.bat` (ويندوز) أو `./run_masar.sh`.
3b. ضع في `.env` السطر `MASAR_ACCESS_CODE=رمز-تختاره-أنت`.
4. افتح http://127.0.0.1:8787 — شاشة فيها «تسجيل الدخول» و«إنشاء حساب مدير». الإنشاء يتطلب رمزك؛ من أدخله صحيحًا ينشئ حساب مدير بالاسم وكلمة المرور التي يختارها، وبعدها يدخل بهما دائمًا. لا حد لعدد الحسابات. بعد 5 محاولات خاطئة (دخول أو رمز) يُقفل المصدر 5 دقائق.
من أجهزة أخرى في الشبكة: `http://IP-الجهاز:8787`.

## المعمارية
واجهة ← API ← SQLite واحدة (`data/masar.db`) = مصدر الحقيقة. لا localStorage للبيانات. الواجهة لا تُظهر نجاحًا إلا بعد تأكيد السيرفر.
Worker داخل السيرفر يعمل والمتصفح مغلق: يفحص الأقساط المتأخرة ويرسل الإشعارات من `notification_outbox`.

## الأدوار
admin (كل شيء + مستخدمون + حذف نهائي + نسخ) | management | teacher (حضور ودرجات) | accountant (مالية) | read_only. الحماية في السيرفر.

## الأقساط
عند إضافة قسط حدّد "التجديد كل كم شهر". عند السداد الكامل: يُلغى إشعار التأخير، يُنشأ القسط التالي، ويصل ولي الأمر رسالة بالمبلغ وآخر موعد.

## واتساب (يحتاج بياناتك)
- الإرسال: `WHATSAPP_ACCESS_TOKEN` + `WHATSAPP_PHONE_NUMBER_ID` + `WHATSAPP_TEMPLATE_NAME` (قالب معتمد جسمه `{{1}}`).
- الاستقبال: في لوحة Meta سجّل Callback URL = `https://نطاقك/api/whatsapp/webhook` (يلزم عنوان HTTPS عام، مثل Cloudflare Tunnel/ngrok/Nginx) و Verify Token = `WHATSAPP_VERIFY_TOKEN`، واشترك في حقل `messages`، وضع `WHATSAPP_APP_SECRET`.
- الرسائل الواردة تظهر في ⚙ لوحة المدير مربوطة بالطالب عبر رقم ولي الأمر.

## النسخ الاحتياطي
تلقائي يوميًا إلى `backups/` (آخر 14) + يدوي من ⚙. استعادة: من ⚙ أو `python restore_backup.py الملف.db` والسيرفر متوقف.

## الاختبار
`bash tests/run_all.sh` (يحتاج node + playwright لاختبار الواجهة).
